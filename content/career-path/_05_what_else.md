{{< slide class="navy" >}}

{{< lane n="1" art="mobile" name="Mobile." what="Apps in your pocket." like="you want your app on your mom’s phone." start="Flutter, or Kotlin and Swift|Put one app on your own phone|Make it call a real API" >}}

{{% note %}}
**Mobile (1 min).** Two ways in: native (Kotlin for Android, Swift for iPhone) or one codebase for both (Flutter, React Native). Same APIs as the web. A lot of the hard work is crashes, slow networks, 4% battery, and app store reviews.
{{% /note %}}

---

{{< lane n="2" art="devops" name="DevOps & cloud." what="Gets code to users. Keeps it running." like="you love automating boring work." start="Linux and the terminal|Docker|One GitHub Action that runs your tests" >}}

{{% note %}}
**DevOps & cloud (1 min).** Remember Java4Shell? Rolling the fix out to hundreds of services is this job. Building the pipeline, the servers, the alerts so you sleep through 2 AM. AWS or Azure certificates help here more than on most paths.
{{% /note %}}

---

{{< slide class="navy" >}}

{{< lane n="3" art="qa" name="QA automation." what="Breaks the app before users do." like="you can’t let a bug go." start="Testing basics|Selenium or Playwright|Ten tests for a friend’s project" >}}

{{% note %}}
**QA automation (1 min).** Manual testing is where many start. Automation is where it grows: you write code that tests code. Also called quality engineering (QE). Many people move from here to backend later.
{{% /note %}}

---

{{< lane n="4" art="data" name="Data." what="Finds answers hiding in data." like="you love numbers and asking “but why?”" start="SQL|Python and pandas|One public dataset, one surprising chart" >}}

{{% note %}}
**Data (1 min).** Data analyst is often the easiest door in. Data science goes deeper into statistics. Data engineering moves the data around. All three start with SQL.
{{% /note %}}

---

{{< slide class="navy" >}}

{{< lane n="5" art="security" name="Security." what="Thinks like an attacker to protect the app." like="you love puzzles and finding holes." start="Networks and Linux basics|The OWASP Top 10|TryHackMe or a CTF" >}}

{{% note %}}
**Security (1 min).** Java4Shell started here: someone found the hole. Capture the Flag competitions (CTFs) are free, fun, and the best way to try it.
{{% /note %}}

---

{{< lane n="6" art="networks" name="Networks." what="Keeps everything connected." like="you want to know what happens when you press Enter." start="How the internet works|Cisco Packet Tracer|CCNA, once you’re sure" >}}

{{% note %}}
**Networks (1 min).** Computer engineering students, this is home turf. A lot of it lives in the cloud now, so networks plus cloud is a strong mix.
{{% /note %}}

---

{{< slide class="navy" >}}

{{< lane n="7" art="ux" name="UI/UX design." what="Decides how the app feels to use." like="you notice when a button is in the wrong place." start="Figma|Redesign one screen you hate|Test it with five friends" >}}

{{% note %}}
**UI/UX design (1 min).** UX is understanding people. UI is how it looks. You don't need to draw well. You need to watch people closely. Point at the Norman door: if a door has a pull handle and a sign that says PUSH, people will still pull it.
{{% /note %}}

---

{{< lane n="8" art="product" name="Product manager." what="Decides what to build, and why." like="you love people and the big picture." start="Talk to real users|Write a one-page plan|Often comes after a few years in tech" >}}

{{% note %}}
**Product manager (1 min).** They don't write the code. They decide what's worth building. Everyone wants ten features. The PM says No to nine so the team ships the one users actually need.
{{% /note %}}

---

{{< slide class="navy" >}}

{{< lane n="9" art="tpm" name="Program manager." what="Keeps big projects on track across many teams." like="you’re the one who organizes the group project." start="Lead a club or a team project|Learn how software gets built|Usually a later move" >}}

{{% note %}}
**Program manager / TPM (1 min).** TPM means technical program manager. When five teams have to ship one thing together on launch day, this is the person who keeps it moving. Most TPMs were engineers first.
{{% /note %}}

---

{{< lane n="10" art="lowcode" name="Low code." what="Builds apps from ready blocks, plus a little code." like="you want to solve business problems fast." start="Power Apps or OutSystems|Automate one boring task|Still learn the basics" >}}

{{% note %}}
**Low code (1 min).** Companies use these tools to build internal apps fast. Real jobs, especially in banks and big companies. The basics from Part One still matter.
