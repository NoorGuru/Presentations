SO WE BUILT

EG Wizard.

Human in the loop or Autonomous

Upgrades apps to new framework versions. Safely. Consistently.

01 Check What does this app need? Versions, dependencies, risky code. MCP · reads team docs
02 Upgrade Recipes for known changes. AI for the messy, repo-specific parts. Skills · the playbook
03 Validate Build, tests, checks. Fails? Read the error, fix, retry. Agent · retry loop
04 Summarize Plain-English report: what changed, what needs a human. LLM · explains it
Either mode: a human reviews every change before it merges.
